# Package roadmap

[Documentation index](index.md)

The following are future additions, outside this release:

- Artisan diagnostics plus dataset-scoped warm, refresh, clear, and offline-cache commands.
- Native multi-district fluent queries and streamed CSV/JSON exports that retain availability reasons.
- An optional persistence adapter with queued imports, unique natural keys, upserts, and resumable progress.
- Persistent source revision history and broader cross-dataset comparison APIs beyond the agent analysis tools.
- Additional PDE datasets after their layouts, units, historical coverage, and privacy markers are backed by fixtures.

The dataset catalog and optional AI/MCP tools are implemented; see [AI integrations](ai.md). Prioritize diagnostics next so consumers can prepare caches and diagnose source gaps.
